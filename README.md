## English

### 👋 Introduction

Welcome to **Piglette AI** – the pinnacle (or perhaps the abyss) of artificial intelligence technology, created by the questionable geniuses at **NeuroOverlord 2025™**. This project is a web interface for interacting with the unique Piglette family of AI models. Unlike boring corporate AIs, Piglette AI has personality, a sense of humor (mostly sarcastic), and a penchant for the absurd.

### ✨ Key Features

*   **🧠 Diverse AI Models:** Choose from a whole family of Piglette AI models, each with its *unique* characteristics:
    *   `Piglette-1` / `Piglette-1-mini`: For basic communication and everyday tasks (or if you're short on cash).
    *   `Piglette-2`: An advanced model for more complex dialogues.
    *   `Piglette-ND1` / `Piglette-ND1-mini`: "Not Dumb" models for scientific and logical reasoning of varying complexity.
    *   `Piglette-MESIAH`: The legendary messiah model for wise decisions and quantum predictions (available for a *small* fee).
    *   *Special Models (secret/future):* `PRIMORDIAL`, `TECHNOSOPHIA`.
*   **💬 Request Interface:** A simple and intuitive interface for sending requests to the selected AI model. Supports text input and choice of response language (Russian, Ukrainian, English).
*   **🚀 "Features" (Beta):** A section with *promising* but currently inactive features like web search, research, chat history, context, file handling, personalization, voice API, and API calls. The exploding card animation hints at their current functionality.
*   **💎 Subscriptions:** Several subscription tiers for access to enhanced features:
    *   *Free:* Basic functionality with delays and limitations.
    *   *Basic:* Slightly fewer limitations, access to Piglette-ND1-mini.
    *   *Professional:* Priority responses, simulated empathy, NFT certificate, VIP support, full access to Piglette-ND1.
    *   *Messiah:* All Professional benefits plus access to Piglette-MESIAH, a metaverse passport, and (non-)guaranteed enlightenment.
*   **📜 NFT Certificate of Importance:** A unique (and utterly useless in the real world) NFT confirming your *exceptional importance* in the Piglette metaverse. Available for "Professional" tier subscribers and above.
*   **🛂 Metaverse Passport:** An official (and equally absurd) document identifying you in the Piglette metaverse. Includes your name, photo (pig icon), sarcasm resistance level, and oinking propensity index. Available for "Messiah" tier subscribers.
*   **❓ FAQ (Frequently Asked Questions):** An extensive section answering the most important (and not-so-important) questions about Piglette AI, its capabilities, ethics, and reason for existence. Written in the signature sarcastic style.
*   **🏆 Hall of Fame:** A collection of the most outstanding, funniest, or deepest user prompts. Other users can rate these prompts.
*   **📞 Tech Support:** Two levels of support:
    *   *Standard:* Available to everyone, response not guaranteed.
    *   *VIP:* For Pro+ subscribers, response is just as useless but faster and gilded.
*   **💬 Tech Chat:** An exclusive chat with VIP support (uses AI to generate support responses).
*   **⚙️ Debug Panel:** A section for developers and testers allowing:
    *   Testing various captcha types.
    *   Managing subscription status.
    *   Viewing and deleting Cookies, LocalStorage, IndexedDB.
    *   Managing tab visibility.
    *   Viewing notes about AI models.
    *   Calling various JS functions for testing.
*   **🐷 Pig-themed "Features":**
    *   *Humor and Sarcasm:* The AI's primary communication tone.
    *   *Captcha:* Diverse and often absurd captchas (text, math, image selection, rotation, puzzles, captcha memes, "real life", etc.) to confirm actions.
    *   *Golden Eggs:* A hidden achievement system with unique effects.
    *   *NFT & Passport:* Humorous digital items.
    *   *Legal Info:* Written in "Comic Sans" with maximum non-seriousness.
    *   *Username Rating:* An absurd algorithm for rating the user's name during registration.
    *   *Animations:* Various animations for buttons, icons, loading states, etc.
*   **👤 Registration & Personalization:** Option to provide a name and gender for (in)significant experience personalization.
*   **📢 Update Notifications:** A modal window informing users about new versions and changes, with the ability to mark them as read.
*   **🧩 DLCs (Downloadable Content):** Ability to enable/disable additional modules (Gallery, Merch, Golden Eggs) via a control panel.

### 🛠️ Technology

The web interface is built using standard web technologies:

*   CSS3 (utilizing CSS variables for theming)
*   JavaScript (Vanilla JS)
