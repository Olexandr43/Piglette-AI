## Русский

### 👋 Вступ

Ласкаво просимо до **Piglette AI** – вершини (або, можливо, дна) технологій штучного інтелекту, створеної сумнівними геніями з **NeuroOverlord 2025™**. Цей проект є веб-інтерфейсом для взаємодії з унікальною лінійкою AI-моделей сімейства Piglette. На відміну від нудних корпоративних AI, Piglette AI має характер, почуття гумору (переважно саркастичне) і схильність до абсурду.

### ✨ Основні можливості

*   **🧠 Різноманітні AI-моделі:** Вибирайте з цілого сімейства AI-моделей Piglette, кожна зі своїми *унікальними* особливостями:
    *   `Piglette-1` / `Piglette-1-mini`: Для базового спілкування та повсякденних завдань (або якщо у вас обмаль грошей).
    *   `Piglette-2`: Продвинута модель для складніших діалогів.
    *   `Piglette-ND1` / `Piglette-ND1-mini`: Моделі "Not Dumb" для наукових та логічних міркувань різного ступеня складності.
    *   `Piglette-MESIAH`: Легендарна модель-месія для мудрих рішень та квантових прогнозів (доступна за *невелику* плату).
    *   *Спеціальні моделі (секретні/майбутні):* `PRIMORDIAL`, `TECHNOSOPHIA`.
*   **💬 Інтерфейс запитів:** Простий та інтуїтивно зрозумілий інтерфейс для надсилання запитів до обраної моделі AI. Підтримує введення тексту та вибір мови відповіді (Русский, Українська, English).
*   **🚀 "Функції" (Beta):** Розділ з *перспективними*, але поки що неактивними функціями, такими як пошук в інтернеті, дослідження, історія чату, контекст, робота з файлами, персоналізація, голосовий API та виклики API. Анімація вибуху картки натякає на їхню поточну працездатність.
*   **💎 Підписки:** Кілька рівнів підписки для доступу до розширених можливостей:
    *   *Безкоштовний:* Базовий функціонал із затримками та обмеженнями.
    *   *Базовий:* Трохи менше обмежень, доступ до Piglette-ND1-mini.
    *   *Професіонал:* Пріоритетні відповіді, імітація емпатії, NFT-сертифікат, VIP-підтримка, повний доступ до Piglette-ND1.
    *   *Месія:* Усі переваги Професіонала плюс доступ до Piglette-MESIAH, метавселенський паспорт та (не)гарантоване просвітлення.
*   **📜 NFT-сертифікат важливості:** Унікальний (і абсолютно марний у реальному світі) NFT, що підтверджує вашу *виняткову важливість* у метавсесвіті Piglette. Доступний для підписників рівня "Професіонал" та вище.
*   **🛂 Метавселенський паспорт:** Офіційний (і настільки ж абсурдний) документ, що засвідчує вашу особу в метавсесвіті Piglette. Містить ваше ім'я, фото (іконка свині), рівень опору сарказму та індекс схильності до хрюкання. Доступний для підписників рівня "Месія".
*   **❓ FAQ (Часті запитання):** Великий розділ із відповідями на найважливіші (і не дуже) питання про Piglette AI, його можливості, етику та сенс існування. Написано у фірмовому саркастичному стилі.
*   **🏆 Зал Слави:** Колекція найвидатніших, найсмішніших чи найглибших запитів від користувачів. Інші користувачі можуть оцінювати ці запити.
*   **📞 Технічна підтримка:** Два рівні підтримки:
    *   *Стандартна:* Доступна всім, відповідь не гарантована.
    *   *VIP:* Для підписників Pro+, відповідь така ж марна, але швидша та з позолотою.
*   **💬 Тех. Чат:** Ексклюзивний чат із VIP-підтримкою (використовує AI для генерації відповідей підтримки).
*   **⚙️ Панель дебагу:** Розділ для розробників та тестувальників, що дозволяє:
    *   Тестувати різні типи капч.
    *   Керувати станом підписки.
    *   Переглядати та видаляти Cookies, LocalStorage, IndexedDB.
    *   Керувати відображенням вкладок.
    *   Переглядати нотатки про AI-моделі.
    *   Викликати різні JS-функції для тестування.
*   **🐷 Свинячі "фішки":**
    *   *Гумор та Сарказм:* Основний тон спілкування AI.
    *   *Капча:* Різноманітні та часто абсурдні капчі (текстові, математичні, вибір картинок, обертання, пазли, капча-меми, "реальне життя" тощо) для підтвердження дій.
    *   *Золоті Яйця:* Прихована система досягнень з унікальними ефектами.
    *   *NFT та Паспорт:* Гумористичні цифрові предмети.
    *   *Юридична інформація:* Написана в стилі "Comic Sans" із максимальною несерйозністю.
    *   *Оцінка імені користувача:* Абсурдний алгоритм оцінки імені під час реєстрації.
    *   *Анімації:* Різноманітні анімації для кнопок, іконок, завантаження тощо.
*   **👤 Реєстрація та Персоналізація:** Можливість вказати ім'я та стать для (не)значної персоналізації досвіду.
*   **📢 Сповіщення про оновлення:** Модальне вікно, що інформує користувачів про нові версії та зміни, з можливістю відзначити прочитане.
*   **🧩 DLCs (Downloadable Content):** Можливість вмикати/вимикати додаткові модулі (Галерея, Магазин, Золоті Яйця) через панель керування.

### 🛠️ Технології

Веб-інтерфейс створений з використанням стандартних веб-технологій:

*   HTML5
*   CSS3 (з використанням змінних CSS для теми)
*   JavaScript (Vanilla JS)

1.  Клонуйте репозиторій.

### 👋 Introduction

Welcome to **Piglette AI** – the pinnacle (or perhaps the abyss) of artificial intelligence technology, created by the questionable geniuses at **NeuroOverlord 2025™**. This project is a web interface for interacting with the unique Piglette family of AI models. Unlike boring corporate AIs, Piglette AI has personality, a sense of humor (mostly sarcastic), and a penchant for the absurd.

### ✨ Key Features

*   **🧠 Diverse AI Models:** Choose from a whole family of Piglette AI models, each with its *unique* characteristics:
    *   `Piglette-1` / `Piglette-1-mini`: For basic communication and everyday tasks (or if you're short on cash).
    *   `Piglette-2`: An advanced model for more complex dialogues.
    *   `Piglette-ND1` / `Piglette-ND1-mini`: "Not Dumb" models for scientific and logical reasoning of varying complexity.
    *   `Piglette-MESIAH`: The legendary messiah model for wise decisions and quantum predictions (available for a *small* fee).
    *   *Special Models (secret/future):* `PRIMORDIAL`, `TECHNOSOPHIA`.
*   **💬 Request Interface:** A simple and intuitive interface for sending requests to the selected AI model. Supports text input and choice of response language (Russian, Ukrainian, English).
*   **🚀 "Features" (Beta):** A section with *promising* but currently inactive features like web search, research, chat history, context, file handling, personalization, voice API, and API calls. The exploding card animation hints at their current functionality.
*   **💎 Subscriptions:** Several subscription tiers for access to enhanced features:
    *   *Free:* Basic functionality with delays and limitations.
    *   *Basic:* Slightly fewer limitations, access to Piglette-ND1-mini.
    *   *Professional:* Priority responses, simulated empathy, NFT certificate, VIP support, full access to Piglette-ND1.
    *   *Messiah:* All Professional benefits plus access to Piglette-MESIAH, a metaverse passport, and (non-)guaranteed enlightenment.
*   **📜 NFT Certificate of Importance:** A unique (and utterly useless in the real world) NFT confirming your *exceptional importance* in the Piglette metaverse. Available for "Professional" tier subscribers and above.
*   **🛂 Metaverse Passport:** An official (and equally absurd) document identifying you in the Piglette metaverse. Includes your name, photo (pig icon), sarcasm resistance level, and oinking propensity index. Available for "Messiah" tier subscribers.
*   **❓ FAQ (Frequently Asked Questions):** An extensive section answering the most important (and not-so-important) questions about Piglette AI, its capabilities, ethics, and reason for existence. Written in the signature sarcastic style.
*   **🏆 Hall of Fame:** A collection of the most outstanding, funniest, or deepest user prompts. Other users can rate these prompts.
*   **📞 Tech Support:** Two levels of support:
    *   *Standard:* Available to everyone, response not guaranteed.
    *   *VIP:* For Pro+ subscribers, response is just as useless but faster and gilded.
*   **💬 Tech Chat:** An exclusive chat with VIP support (uses AI to generate support responses).
*   **⚙️ Debug Panel:** A section for developers and testers allowing:
    *   Testing various captcha types.
    *   Managing subscription status.
    *   Viewing and deleting Cookies, LocalStorage, IndexedDB.
    *   Managing tab visibility.
    *   Viewing notes about AI models.
    *   Calling various JS functions for testing.
*   **🐷 Pig-themed "Features":**
    *   *Humor and Sarcasm:* The AI's primary communication tone.
    *   *Captcha:* Diverse and often absurd captchas (text, math, image selection, rotation, puzzles, captcha memes, "real life", etc.) to confirm actions.
    *   *Golden Eggs:* A hidden achievement system with unique effects.
    *   *NFT & Passport:* Humorous digital items.
    *   *Legal Info:* Written in "Comic Sans" with maximum non-seriousness.
    *   *Username Rating:* An absurd algorithm for rating the user's name during registration.
    *   *Animations:* Various animations for buttons, icons, loading states, etc.
*   **👤 Registration & Personalization:** Option to provide a name and gender for (in)significant experience personalization.
*   **📢 Update Notifications:** A modal window informing users about new versions and changes, with the ability to mark them as read.
*   **🧩 DLCs (Downloadable Content):** Ability to enable/disable additional modules (Gallery, Merch, Golden Eggs) via a control panel.

### 🛠️ Technology

The web interface is built using standard web technologies:

*   HTML5
*   CSS3 (utilizing CSS variables for theming)
*   JavaScript (Vanilla JS)

### 🚀 Running Locally

1.  Clone the repository.
2.  Open the `PigletteAI.html` file in your web browser.
3.  *Note:* Some features (e.g., API interactions, IndexedDB storage) might require running through a local web server (like Python's `http.server` or VS Code's Live Server) due to browser security policies regarding the `file://` protocol.

2.  **Якщо ви хочете, щоб похідні проекти також були відкритими (Copyleft):**
