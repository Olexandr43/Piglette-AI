# Piglette AI 🐷

(Не)серьёзный AI‑генератор свинячих мемов, шуток, загадок, капч и «золотых яиц».  
Мини‑игра, мерч, галерея AI‑искусства.

**Сайт:** https://piglette-ai.vercel.app/

## Функции

- Генерация мемов, шуток, загадок, фактов и капч со свинками  
- Игра «Золотые яйца»  
- Магазин мерча  
- Галерея AI‑артов

## Стек

- Next.js + React  
- Vercel deployment  
- KaTeX, Leaflet
